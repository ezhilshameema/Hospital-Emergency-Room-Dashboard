🏥 Hospital Emergency Room Dashboard | Power BI

 📌 Project Overview

This project focuses on analyzing Hospital Emergency Room (ER) data using Microsoft Power BI. The dashboard provides insights into patient admissions, waiting times, patient satisfaction, patient demographics, and referral patterns.

The objective is to monitor emergency room performance, identify operational trends, and support data-driven decision-making for better hospital resource management.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation
- Data Visualization

 📊 Dashboard Overview

The dashboard includes the following analytical sections:

 1. Key Performance Indicators (KPIs)
- Total Number of Patients
- Average Patient Wait Time
- Patient Satisfaction Score
- Number of Patients Referred

2. Patient Admission Analysis
- Admitted vs. Not Admitted Patients
- Admission Status Distribution
- Percentage Distribution of Patient Admissions

3. Patient Waiting Time Analysis
- Average Waiting Time in Minutes
- Patients Seen Within 3 Minutes
- Waiting Time Performance

 4. Patient Demographic Analysis
- Patient Referrals by Age Group
- Gender-wise Patient Distribution
- Race-wise Patient Distribution

 5. Operational Analysis
- Patient Visits by Day of the Week
- Patient Visits by Hour
- Monthly and Yearly Patient Trends

📈 Key Insights

Based on the April 2024 dashboard view:

| Metric | Value |

Additional observations:

- Patient visits can be analyzed by day and hour.

- Monthly and yearly filters enable time-based analysis.
